# ✅ Sistema de Gerenciamento de Tarefas com IA

Aplicação de gerenciamento de tarefas criada para explorar **desenvolvimento full stack, React, Node.js e recursos de Inteligência Artificial**.

O objetivo do projeto é centralizar tarefas e explorar automações e recursos inteligentes para produtividade.

## 📂 Estrutura atual

O código do projeto está na pasta `Lista de tarefas IA/`, que contém frontend, backend, código-fonte e configurações de deploy.

## ▶️ Executando localmente

```bash
git clone https://github.com/Lehguto12/Lista-de-tarefas-IA.git
cd Lista-de-tarefas-IA/"Lista de tarefas IA"
npm install
cd client
npm install
```

Depois, configure as variáveis de ambiente necessárias e execute o projeto conforme os scripts disponíveis no `package.json`.

## 🎯 Objetivo do projeto

Praticar conceitos importantes para desenvolvimento profissional, incluindo React, APIs REST, backend com Node.js, banco de dados e integração de serviços.
